## Toolchain
- C++20; Windows = **MSVC / clang-cl, never MinGW**; Linux = **LLVM/Clang + lld,
  never GCC** (closest parity to the MSVC primary; GCC diverges on C++20 corners).
- Deps: OpenSSL, zlib (+ optional brotli/zstd) via find_package/vcpkg. No CPM/coroio/Python.

### Linux container test lanes (CI parity, both **Clang/lld**, never GCC)
- `Dockerfile.linux-h3-test` — HTTP/3 + WebTransport lane. Builds **OpenSSL 3.6
  from source** (`linux-x86_64-clang`; the 3.5+ QUIC-TLS API HTTP/3 needs, vs
  Ubuntu's 3.0) into `/opt/openssl`, configures `HTTP3=ON WEBRTC=ON TESTS=ON`,
  epoll async backend. Gate: `ctest -R "Quic|Http3|Qpack"` → **75/75 green**.
- `Dockerfile.linux-test` — WebRTC/SFU-relay lane. System OpenSSL (3.0; DTLS/SRTP
  only, HTTP3=OFF), `WEBRTC=ON`, epoll async backend. Gate:
  `ctest -R "Media|Srtp|Dtls|Ice|Turn|..."` → **96/96 green** (incl.
  MediaRelay/MediaEcho). `docker run --rm boltapi-linux-test` re-runs it.

  CXX=clang++`, cmake configured with explicit
  `-DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++
  -DCMAKE_EXE_LINKER_FLAGS=-fuse-ld=lld` (never auto-detect). `WARNINGS_AS_ERRORS=OFF`
  (the suite is MSVC-primary `/WX`; running the gate on Linux is the point).
